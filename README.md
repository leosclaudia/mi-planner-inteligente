# Mi Planner Inteligente

Crear una aplicación web móvil real llamada provisionalmente “Planner Inteligente Personalizable”. Debe ser mobile-first, en español, visualmente cálida, limpia y profesional, con sensación de agenda/planner premium y controles grandes para usar con el dedo. NO es un PDF.

Primera versión funcional:
- Inicio/dashboard con fecha, saludo, resumen de pendientes y accesos rápidos.
- Día, Semana y Mes con navegación real.
- Tareas: crear, completar, editar y eliminar.
- Proyectos: crear, editar y eliminar.
- Secciones personalizables: el usuario puede cambiar nombre e icono, ocultar/mostrar, reordenar y crear nuevas. No dejar “Huerta” fija en el producto base.
- Pantalla “Personalizar mi planner”.
- Plantillas opcionales de secciones: Trabajo, Estudio, Negocio, Huerta, Bienestar, Contenido, Ventas y una sección personalizada.
- Asistente: por ahora interfaz funcional para escribir pendientes desordenados y convertirlos en una propuesta organizada; dejar arquitectura preparada para integrar IA real después.
- Configuración inicial de ejemplo para la propietaria: Proyectos, Huerta, Pedidos/Ventas y Contenido, pero separada del producto genérico.
- Persistir todos los datos y la configuración localmente en el navegador para que al cerrar y volver a abrir no desaparezcan.
- Diseño responsive para celular y tablet.
- Navegación inferior móvil: Inicio, Calendario, Tareas, Asistente y Más.
- Incluir onboarding corto la primera vez: nombre del planner y selección de secciones.
- Todo debe poder probarse de verdad desde el preview: botones y formularios funcionando, no pantallas decorativas.

Priorizar primero una base sólida y usable. No agregar pagos ni publicación comercial todavía.
